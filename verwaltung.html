Woher bekomme ich den Zugriffsschlüssel?

Den Schlüssel gibt der Verwalter der Medienliste weiter (z. B. persönlich oder über einen Passwortmanager). Er wird nur einmal pro Gerät eingetragen.

Der Schlüssel gilt nur für dieses eine Repository und wird ausschließlich in diesem Browser gespeichert. Wer ihn kennt, kann die Liste ändern. Bitte nicht weitergeben und nicht per E-Mail oder Messenger verschicken.

Für den Verwalter: Schlüssel erstellen
  1. Auf github.com mit dem Konto anmelden, dem das Repository gehört.
  2. Neuen Schlüssel erstellen (Fine-grained personal access token).
  3. Name z. B. „Medienliste“, Ablauf in einem Jahr. Bei Repository access „Only select repositories“ wählen und das Repository der Medienliste auswählen.
  4. Unter Repository permissions bei Contents die Stufe „Read and write“ wählen.
  5. „Generate token“ anklicken und den Schlüssel kopieren (beginnt mit github_pat_). Er wird nur einmal angezeigt.

Läuft der Schlüssel ab oder soll jemand keinen Zugriff mehr haben: unter Settings → Developer settings → Fine-grained tokens löschen und einen neuen erstellen.
